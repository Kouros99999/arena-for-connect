# Languages

The agent panel, supervisor console, results report and wallboard are available in **English, Spanish, French, German and Brazilian Portuguese**.

## Choosing a language

Each page has a language selector in its header. The choice is remembered in that browser, so an agent picks once. Until someone chooses, the page follows the browser's own language, falling back to English. A link can force a language with `?lang=es` (or `fr`, `de`, `pt-BR`), which is handy for a wallboard set up for a floor.

## What is translated

Everything with a fixed meaning: headings, tiles, buttons, placeholders, badge names, goal and trend measures, challenge and kudos sections, and the wallboard. The names of people, teams and queues come from Amazon Connect as they are. Sentences that Arena composes around numbers, such as a race standing or a coaching note, stay in English in this version; they are next.

## Adding a language

Translations live in one file shipped with the pages, keyed by the English text. Send us the strings in your language and we add it, or, if you host the pages yourself, add a column to that file.
